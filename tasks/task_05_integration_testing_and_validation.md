# Task: 05 — Integration, Regression & Calculation Validation

Status: pending
Priority: high

## 1. Overview

### ما المشكلة؟
عند إضافة ميزات مالية متعددة تتداخل فيها الحسابات (ربط المراحل، كشوف حسابات الموردين، إحصائيات الواردات، ومؤشرات المشاريع العلوية)، تزداد احتمالية حدوث أخطاء حسابية مثل احتساب نفس المعاملة مرتين (Double Counting)، أو عدم تزامن الأرقام بين الصفحات المختلفة، أو كسر التوافقية العكسية مع البيانات المخزنة مسبقاً.

### ما المطلوب؟
1. إجراء اختبارات تكاملية شاملة (End-to-End Integration Testing) لجميع الميزات الجديدة للتأكد من أنها تعمل كوحدة واحدة متماسكة.
2. التحقق الدقيق من صحة الحسابات الرياضية ومطابقتها لمعادلات النظام المعتمدة.
3. التأكد من أن جميع الإجماليات تعتمد على مصدر حقيقة وحيد (`calc.js` + `store.js`).
4. اختبار استقرار النظام والتوافقية العكسية (Backward Compatibility) مع البيانات القديمة.
5. التحقق من تجربة المستخدم عبر المتصفحات والأجهزة المختلفة، وتدقيق دعم الطباعة العربية RTL.

## 4. Implementation Plan

1. **الخطوة 1: مراجعة الدوال الحسابية وتوحيدها**: التأكد من أن جميع العمليات تستدعي دوال `calc.js` ولا تقوم بحساب يدوي منفصل داخل الـ UI.
2. **الخطوة 2: اختبار التوافقية العكسية**: فتح مشاريع قديمة ومعاملات سابقة للتأكد من عدم حدوث أخطاء JavaScript في الـ Console.
3. **الخطوة 3: تنفيذ سيناريوهات دورة الحياة الكاملة**: من إضافة مشروع وإدخال الربح المتوقع، إلى تسجيل المصاريف على المراحل، واستخراج كشف الحساب، وتدقيق المؤشرات العلوية.
4. **الخطوة 4: مراجعة جودة التصميم والطباعة**: التحقق من خطوط اللغة العربية، اتجاه RTL، التجاوب على الهواتف، ومظهر طباعة الـ PDF.

## 6. Testing Checklist

- [ ] إضافة مصروف بدون مرحلة -> يعمل بشكل طبيعي كمصروف عام.
- [ ] إضافة مصروف مرتبط بمرحلة -> يحدث تكلفة المرحلة في الحال.
- [ ] إضافة مصروفين لنفس المرحلة -> يتم جمعهما بشكل صحيح دون Double Counting.
- [ ] التأكد من ظهور تكلفة المرحلة في بطاقة المرحلة وفي جدول سجل الحالات.
- [ ] إنشاء كشف حساب لمورد -> يعرض البيانات المفلترة بالفترة المحددة بدقة.
- [ ] إنشاء كشف حساب لمقاول -> يعرض البيانات المفلترة بالفترة المحددة بدقة.
- [ ] تطبيق خصم في كشف الحساب -> يتم خصم المبلغ من الرصيد المتبقي وتسجيله.
- [ ] طباعة PDF -> تظهر ورقة كشف حساب عربية أنيقة جاهزة للطباعة.
- [ ] التأكد من صحة إجمالي الوارد في صفحة الحسابات وصفحة المشاريع.
- [ ] التأكد من صحة إجمالي الصادر في صفحة الحسابات وصفحة المشاريع.
- [ ] التأكد من صحة الفرق (`الوارد - الصادر`).
- [ ] التأكد من إمكانية تعديل وحفظ الربح المتوقع.
- [ ] التأكد من صحة معادلة الربح الفعلي (`الربح المتوقع + الفرق`).

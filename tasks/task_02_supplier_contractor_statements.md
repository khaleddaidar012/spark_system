# Task: 02 — Supplier & Contractor Statements, Deductions & PDF Export

Status: pending
Priority: high

## 1. Overview

### ما المشكلة؟
في صفحتي **المقاولين** و**الموردين**، يحتاج مسؤولو الحسابات والمهندسون إلى استخراج ومراجعة كشف حساب تفصيلي ("كشف حساب") لأي مورد أو مقاول عن فترة زمنية محددة (من تاريخ إلى تاريخ)، لمعرفة إجمالي مستحقاته، الدفعات المسلمة له، الخصومات المطبقة عليه بسبب التأخير أو التلفيات، وصافي الرصيد النهائي المستحق، مع إمكانية طباعة هذا الكشف كتقرير PDF رسمي ومعتمد باللغة العربية.

### ما المطلوب؟
1. إضافة زر واضح باسم **"كشف حساب"** في صفحة المقاولين وصفحة الموردين لكل شخص.
2. فتح واجهة/نافذة كشف الحساب تتيح تحديد:
   - تاريخ البداية (`From Date`)
   - تاريخ النهاية (`To Date`)
   - المقاول / المورد
3. عرض جدول الحساب التفصيلي متضمناً: (التاريخ، نوع العملية، الوصف، المشروع المرتبط، الوارد، الصادر/المدفوع، الخصومات، والرصيد المتحرك) مع الإجماليات في الأسفل.
4. إتاحة إمكانية **تطبيق خصم** جديد على كشف الحساب وتوثيقه مع ذكر السبب وقيمته.
5. توفير زر **"طباعة PDF"** لتوليد وتصدير كشف حساب احترافي جاهز للطباعة بحجم A4 يدعم اللغة العربية واتجاه RTL وتنسيق الطباعة الرسمي.

### لماذا نحتاج هذه الـ Feature؟
لتسوية الحسابات المالية مع المقاولين وموردي الخامات بدقة متناهية، وتوثيق الخصومات المالية رسمياً، وتقديم كشوفات حساب ورقية أو رقمية موقعة ومعتمدة.

### ما الأجزاء الحالية في المشروع التي ستتأثر؟
- صفحة المقاولين (`contractors.html` و `contractors.js`)
- صفحة الموردين (`suppliers.html` و `suppliers.js`)
- مخزن البيانات (`store.js` لإضافة وتخزين الخصومات `deductions`)
- وحدة الحسابات المالية (`calc.js` لدعم حسابات كشف حساب الشخص بالمدى الزمني)
- شيت الطباعة وأنماط CSS (`statement.css` أو أنماط الطباعة المدمجة)

## 5. API / Store Functions

- **`store.addDeduction(data)`**: إضافة خصم جديد وحفظه.
- **`store.getDeductions(personId, personType, fromDate, toDate)`**: جلب الخصومات المطبقة على الشخص في فترة زمنية.
- **`calc.personAccountStatement({ personId, personType, fromDate, toDate })`**:
  - تجلب جميع العمليات المالية والمشتريات والمدفوعات والخصومات المرتبطة بهذا الشخص ضمن النطاق الزمني.
  - تحسب الرصيد السابق قبل تاريخ البداية (`Opening Balance`).
  - تحسب إجمالي الأعمال / التوريدات، إجمالي المدفوع، إجمالي الخصومات، وصافي الرصيد المتبقي.

## 6. UI Changes & PDF Print Layout

1. **أزرار الواجهة**:
   - إضافة زر `<button class="btn btn-outline btn-statement">كشف حساب</button>` في بطاقات وجداول المقاولين والموردين.
2. **واجهة كشف الحساب المنبثقة**:
   - شريط الفلترة: اختيار تاريخ البداية وتاريخ النهاية، وزر "تحديث/عرض".
   - شريط الإحصائيات السريعة: إجمالي المستحق، إجمالي المسدد، إجمالي المخصوم، الرصيد المتبقي.
   - جدول المعاملات المفصلة: (التاريخ | البيان | المشروع | المستحق | المدفوع | الخصم | الرصيد).
   - نموذج إضافة خصم سريع: حقل القيمة، حقل سبب الخصم، زر "تطبيق الخصم".
   - زر "طباعة PDF" رئيسي.
3. **مواصفات الـ PDF المطبوع**:
   - **المحرك المستخدم**: `window.print()` مع ميديا كويري `@media print` وقالب HTML نظيف بدون أزرار أو حواف غير مرغوبة.
   - **دعم اللغة العربية**: خط عربي أنيق وواضح (`Cairo` / `Tahoma`) مع اتجاه `dir="rtl"`.
   - **الترويسة والبيانات**: ترويسة شركة المقاولات، اسم المقاول/المورد، رقم الهاتف، الفترة من/إلى، تاريخ استخراج الكشف، جدول المعاملات، جدول الخصومات، والختم والتوقيعات في الأسفل.
   - **اسم ملف الحفظ المقترح**: `كشف_حساب_[اسم_المقاول]_[من]_[إلى].pdf`.
